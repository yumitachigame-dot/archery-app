Archery iPhone PWA

Current menu:
- 点取り (working)
- 本数 (placeholder)
- 消耗品管理 (placeholder)
- 設定 (placeholder)

Scoring distances:
- 18m: 6 arrows/end
- 30m: 3 arrows/end
- 50m: 6 arrows/end
- 70m: 6 arrows/end
- 90m: 6 arrows/end

Point-taking keeps the original tap-target scoring, X/10 counts, undo, end totals and local history.

To use on iPhone:
1. Host these files on an HTTPS static host.
2. Open the URL in Safari.
3. Share -> Add to Home Screen.
